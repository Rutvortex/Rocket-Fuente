# Proyecto MERN CRUD con Autenticacion
Aplicacion web fullstack con registro de usuarios, login con JWT
y un CRUD protegido, desarrollada con el stack MERN.

## Tecnologias utilizadas
- MongoDB — Base de datos NoSQL
- Express.js — Framework backend
- React — Libreria frontend
- Node.js — Entorno de ejecucion

## Requisitos previos
- Node.js v18+
- MongoDB Atlas o MongoDB local

## Instalacion
git clone https://github.com/Rutvortex/Rocket-Fuente
cd Rocket-Fuente
npm install
cp .env.example .env # Edita .env con tus valores
